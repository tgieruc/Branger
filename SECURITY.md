# Security

Please report vulnerabilities through GitHub's private vulnerability reporting feature. Do not include credentials or personal data in public issues.

Deployments must apply all migrations before deploying updated Edge Functions and clients. Public source code does not configure or secure an existing hosted instance automatically.

Keep Supabase service-role keys, AI provider keys, signing credentials, and production data outside Git. Client-side Supabase keys and EAS project identifiers are public configuration.
